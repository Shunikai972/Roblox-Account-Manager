High-Performance Roblox Account Manager & Executor Platform

Astro Account Manager is an enterprise-grade, secure desktop workspace for managing Roblox account sessions, multi-instance process monitoring, FastFlags optimization, and remote Lua execution via WebSocket RPC.

🚀 Quickstart Guide 📖 REST API Reference

🌟 Platform Architecture & Capabilities

Built from the ground up for high reliability, zero memory leaks, and instant multi-account session management.

🔐

Windows DPAPI Encryption Vault

Session cookies (.ROBLOSECURITY) are encrypted locally using native Windows DPAPI (CurrentUser). Secrets are never logged or stored in plain text.

🌐

Edge CDP Login Engine

Automated browser login via Chromium DevTools Protocol (port 9222). Seamlessly intercepts 100% of HttpOnly session cookies and auto-closes upon validation.

⚡

Potato Mode & FPS Unlocker

Custom FastFlags engine modifying ClientAppSettings.json before launch. Forces low-res textures, zero grass, flat shaders, and 240+ FPS cap for running 10+ accounts on budget hardware.

🚀

Nexus Executor RPC

Built-in WebSocket server (port 5242) for broadcasting Lua scripts, running teleports, monitoring live Roblox print logs, and handling auto-rejoin rules.

📦 Installation & Launching

Run the standalone executable or run directly from source.

Executable Launch (Windows 10 / 11) 
# Option 1: Standalone Single Executable
./dist/AstroAccountManager.exe

# Option 2: Run from Python Source
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python main.py

🥔 Potato Graphics & FPS Frame Unlocker

Run dozens of Roblox clients simultaneously on low-end CPUs/GPUs using optimized FastFlags.

FastFlag Key Applied Value Description
DFIntTaskSchedulerTargetFps 240 / 360 / 60 Frame rate scheduler target for unlocked FPS.
DFIntDebugForceQualityLevel 1 Forces minimum graphics rendering quality level.
FIntDebugTextureManagerSkipMips 16 Skips high-resolution texture mipmaps for ultra-fast load times.
FFlagDebugDisableShadowMap "True" Completely disables shadow map calculation.
FFlagDisableTerrainWater "True" Turns off terrain water shaders and reflections.
FFlagDebugDisableMaterials "True" Replaces PBR materials with flat solid colors.

🚀 Nexus Executor WebSocket Protocol

Broadcast Lua scripts to one or all connected Roblox clients over WebSocket.

WebSocket Client Endpoint & Script Execution 
-- Connect to Nexus WebSocket Server
ws://127.0.0.1:5242/Nexus

-- Message Payload Format (JSON)
{
    "target": "all",  -- Or specific Roblox Username
    "command": "execute",
    "payload": "print('Hello from Astro Nexus Executor!')"
}

🔌 Developer REST API Reference (Port 7963)

Complete REST API compatibility layer for external automation scripts.

Method Endpoint Description
GET /GetAccounts Returns array of all saved Roblox account profiles.
POST /LaunchAccount Launches Roblox for specified account ID and target Place/Job ID.
POST /SetFPSCap Patches ClientAppSettings.json with target FPS limit.
GET /GetNexusStatus Checks if Nexus WebSocket server is running and returns client count.
POST /SendNexusCommand Sends a Lua execution command to connected Roblox clients.

🛡️ Security & Vault Integrity

Designed with strict security guarantees for account session protection.

  • Windows DPAPI CurrentUser Encryption: Master keys stay in local protected system storage.
  • No Remote Tracking: Zero analytics or telemetry sent to third-party servers.
  • Strict Local IPC: REST API and WebSocket interfaces bind to 127.0.0.1 only.
