17. LIMITES ASSUMEES (CE QUE L'APPLICATION NE PEUT PAS FAIRE)
================================================================================
  - Les entrees clavier et souris vont a la fenetre au premier plan. Une fenetre
    minimisee n'est pas pilotee dans ce build.
  - Le plafond FPS de Roblox est global : il ne peut pas differer d'une instance
    a l'autre, y compris via un profil de lancement.
  - Pas de controle audio par processus sur cette machine : les niveaux sont
    memorises, pas appliques.
  - Pas d'API de groupe Roblox : une "party" signifie tout le monde sur le meme
    JobId.
  - Les notifications telephone passent par un relais webhook, il n'y a pas
    d'application mobile.
  - L'auto-rejoin lit les journaux (codes 277, 278...) mais ne voit pas la boite
    de dialogue de deconnexion affichee dans le jeu.
  - L'etat "sans surveillance" est une deduction (en jeu, aucune macro, au-dela
    du delai de veille) : Roblox ne partage pas le minuteur d'inactivite.
  - Le demarrage d'une macro de groupe lance une fenetre, les autres passent en
    file d'attente.

18. VOLONTAIREMENT NON IMPLEMENTE
